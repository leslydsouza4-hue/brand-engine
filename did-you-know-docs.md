# Did You Know — Feature Documentation

## Overview
The **Did You Know** workspace in Brand Engine lets you create branded "Did You Know?" social thumbnails featuring HighLevel team members with customizable text, badges, layouts, and background imagery.

---

## People & Poses

| Person | Poses Available |
|--------|----------------|
| **Andrew George** | 7 poses |
| **Ben Stutzner** | 10 poses |
| **Usma** | 4 poses |

- Select a person from the sidebar, then click through their available poses
- Each pose shows the team member in a different stance/position
- Person position (X/Y) and scale are adjustable via sliders

---

## Layouts

Two layout options:

| Layout | Description |
|--------|-------------|
| **Text Left** | Headline text on the left, person on the right |
| **Text Right** | Headline text on the right, person on the left |

---

## Badge Styles

Three badge styles for the "Did You Know?" pill:

| Style | Color |
|-------|-------|
| **Green** | Green gradient badge |
| **Electric Blue** | Blue gradient badge |
| **Teal** | Teal/cyan gradient badge |

Badge position adjusts automatically based on the selected layout.

---

## Headline Text

- **White Lines** — Main headline text (renders in white)
- **Highlight Lines** — Secondary headline text (renders in light blue #7CC8FF)
- Font size is **fully dynamic** — it automatically scales to be as large as possible without overlapping the HighLevel logo at the bottom
- Text is always uppercase, Poppins font, with drop shadow for readability
- Word count is shown in real-time

---

## Screenshot / Image Layer

Upload a screenshot or image that renders **behind the person** as a depth layer:

- **8 visual styles**: Glow, Float, Neon, Minimal, Tilt, Shadow, Cinematic, Glass
- **Adjustable controls**:
  - Opacity (10–100%)
  - Scale (30–120%)
  - Border Radius (0–40px)
  - Offset X & Y positioning
- **Crop tool** built in for trimming uploaded images
- Supports PNG and JPG

---

## Visual Effects

- **Blue radial glow** behind the person image for depth
- **Orbit rings** decorative element behind the person
- **HighLevel logo** watermark in the bottom corner (auto-positioned per layout)
- **Background**: Uses the branded `bg.png` with orbit ring overlay

---

## Export Options

- **Single Export**: Download individual thumbnails as PNG (1080×1080)
- **Batch Export Queue**: 
  - Add multiple thumbnails to a queue
  - Preview queued thumbnails in a strip
  - Remove individual items from the queue
  - Export all queued thumbnails as a single ZIP file
- Exports are tracked in **My Exports** for easy access later

---

## Quick Workflow

1. Select a person (Andrew, Ben, or Usma)
2. Pick a pose from their gallery
3. Choose a layout (Text Left / Text Right)
4. Pick a badge style (Green / Electric Blue / Teal)
5. Type your headline in White Lines and/or Highlight Lines
6. Optionally upload a screenshot with custom styling
7. Export as PNG or add to batch queue for bulk export
